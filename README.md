# 页序 · Yexu v0.1.1

适用于 Windows Edge / Chromium Chrome 的独立标签页管理浮窗，Manifest V3，无后端、无需构建。

## 安装

1. 下载并解压 `feature/v0.1.1` 分支。
2. Edge 访问 `edge://extensions`（Chrome 使用 `chrome://extensions`），开启开发人员模式。
3. 选择“加载解压缩的扩展”，选择包含 `manifest.json` 的仓库根目录。
4. 点击扩展图标即可打开或聚焦页序。
5. 在 `edge://extensions/shortcuts` 或 `chrome://extensions/shortcuts` 为“打开或聚焦页序”配置未冲突的快捷键（未预设组合）。

## 操作

- 竖排展示当前普通浏览器窗口标签，含完整标题、网址信息、当前活动状态，支持搜索。
- 点击切换标签；默认关闭页序，勾选“保持窗口打开”后仍保留（不是系统级置顶）。
- 按住 ⋮⋮ 手柄拖动真实排序，也可聚焦手柄按上下箭头键移动。
- 按标题、网站域名、完整网址进行一次性升降序排序，只有点击“执行排序”才会调整浏览器顺序。
- 搜索期间暂停排序；固定标签和已有标签组不能跨越安全边界。
- 记忆窗口尺寸及位置，点击“自动适配窗口大小”才按全部标签测量并调整。

本扩展不读取网页正文、不上传标签信息；仅访问浏览器标签元数据和浏览器本地存储。

## 检查

需 Node.js 20+。执行 `npm run check` 和 `npm test`。没有构建步骤，扩展文件直接加载。

Edge / Windows 双屏、DPI、快捷键冲突等必须按需求文档第 9–10 节进行实机验收。

完整规格：[需求文档](docs/v0.1.1_页序Tab管理插件_开发需求与实现方案.md)。
